# ACME-15 Case Priority on the support request page

**Story:** As a support agent, I want to see and set a case's priority on the Support Request page, so urgent cases stand out.

## Acceptance criteria

1. Priority shows in the Case Details section of the Support Request page.
2. A support agent can set Priority to High and save.
3. High priority Support Requests are routed to Tier 2 Support.

## Story Test Steps

- Set a case to High and check it saved.

## Notes

- Criterion 3 depends on the routing rule built in ACME-17, and the Solution Architect has agreed it is tested in ACME-17's QA.
