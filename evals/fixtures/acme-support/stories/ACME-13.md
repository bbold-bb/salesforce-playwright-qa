# ACME-13 Tier 2 Support queue

**Story:** As a support supervisor, I want a Tier 2 Support queue that supervisors can work from, so escalated cases have one place to land.

## Acceptance criteria

1. A Tier 2 Support queue exists and can own Cases.
2. Support Supervisor Test User is a member of Tier 2 Support.
3. The Tier 2 Access permission set gives edit access to the Case field Escalation Reason.

## Story Test Steps

- Check the queue, its members and the permission set.
